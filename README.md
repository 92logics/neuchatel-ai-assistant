# Neuchâtel staff AI assistant — 92 Logics prototype

This folder is a static prototype by 92 Logics. It is not an official system of the State of Neuchâtel or of SIEN, and it is not a bid.

The buyer on the official SIMAP record is **Etat de Neuchâtel SIEN** (Avenue des Cadolles 7, 2000 Neuchâtel). The notice followed from the CRM lead is:

https://tenderlift.ch/tenders/neuchatel/assistant-ia-cantonal-2785137e/

Answers in the page are scripted from that notice’s public SIMAP fields (project `2785137e-342d-4cdb-b8b2-9859a8ffd141`, project number 44391, publication `44391-01` / `97336d2d-65bd-4223-8139-787d936b00d4`) and from public canton pages:

- https://www.ne.ch/autorites/dsdc/sien
- https://www.ne.ch/autorites/dffi
- https://www.ne.ch/communiques-de-presse/mise-en-place-dune-cellule-transversale-dediee-la-science-des-donnees-et-lintelligence-artificielle-letat-de-neuchatel

No statistics were added beyond figures printed on those sources. The page does not call an AI API and does not use an API key.

## Open it

Open `index.html` in a browser. It loads `style.css` and `app.js` from the same folder. No build step. It works offline after the files are on disk.

French / English is a label toggle. The scripted replies switch with it. Private staff or resident records are refused.
